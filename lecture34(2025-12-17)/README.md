"This project is a personal finance dashboard built with React and Vite, designed to practice modern frontend architecture and UI composition. The app presents an 'Overview' screen with a sidebar navigation and modular sections for current balance, income and expenses, savings pots, budget categories, recurring bills, and recent transactions. The interface uses responsive layouts, SVG-based visuals, and reusable components to demonstrate clean styling, layout techniques, and component-driven design patterns suitable for real-world financial dashboards."
